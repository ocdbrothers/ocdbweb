OCDbrothers website — server upload package

1. Extract this ZIP.
2. Upload all contents of the OCDbrothers-Website folder into your server web root (often public_html or www).
3. Keep the assets and services folders in their existing locations.
4. index.html is the homepage. Each service has its own index.html under services/.

Before using a different domain:
Replace https://ocdbrothers-thunder-bay.easycrane26.chatgpt.site with your own HTTPS domain throughout the HTML files, sitemap.xml, robots.txt and llms.txt. This updates canonical URLs, social metadata, structured data and the sitemap location.

The website is static HTML, CSS and JavaScript. No build tools, database or installation are required. It should be hosted at the domain root because asset and page URLs start with /.

The quote form opens the visitor's email app; it does not store enquiries on the server. WhatsApp links use +1 (807) 358-3250. The server must serve index.html automatically for directory URLs such as /services/window-cleaning/.
